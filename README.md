# 😃 Emoji Translator

A simple Python application that converts English words into emojis.

## Features

- Translate words into emojis
- Case-insensitive
- Easy to customize
- Beginner-friendly

## Installation

```bash
git clone https://github.com/yourusername/emoji-translator.git
```

## Run

```bash
python main.py
```

## Example

Input

```
I love python because it is cool
```

Output

```
I love 🐍 because it is 😎
```

## Technologies

- Python 3
- Dictionaries
- Functions
- String Manipulation
